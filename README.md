## 📖 درباره پروژه

<br/>

**تایپ‌سنج** یک ابزار مدرن و جذاب برای اندازه‌گیری سرعت تایپ است.  
به محض اینکه شروع به تایپ کنید، **زمان‌سنج خودکار** روشن می‌شود — بدون نیاز به کلیک دکمه شروع.  
اگر خطا داشته باشید، **کادر قرمز** می‌شود. اگر در حال تایپ درست هستید اما کامل نکرده‌اید، **زرد** می‌شود.  
و وقتی متن را **درست و کامل** تایپ کردید، کادر **سبز** شده و زمان متوقف می‌گردد. ✨

<br/>

## 🎯 ویژگی‌های کلیدی

<br/>

| ویژگی | توضیح |
|-------|--------|
| ⏱️ شروع خودکار تایمر | با فشردن اولین کلید |
| 🔴🟡🟢 بازخورد رنگی | خطا ← قرمز / ناقص صحیح ← زرد / کامل صحیح ← سبز |
| 📝 تغییر متن نمونه | انتخاب جمله جدید با یک کلیک |
| 📊 نمایش سرعت | بر حسب کاراکتر در دقیقه (CPM) و کلمه در دقیقه (WPM) |
| 🔄 تلاش مجدد | reset کامل با حفظ متن نمونه |
| 🖌️ فونت اختصاصی | **BYekan** — زیبا و خوانا برای فارسی |

## 🚀 نحوه استفاده

<br/>

1. پروژه را دانلود کنید
2. فایل `index.html` را در مرورگر باز کنید
3. تایپ را در کادر شروع کنید — زمان شروع می‌شود ⏳
4. اگر اشتباه تایپ کنید: کادر قرمز می‌شود 🔴
5. اگر درست ولی ناقص تایپ کنید: کادر زرد می‌شود 🟡
6. وقتی دقیقاً مثل متن نمونه کامل کردید: کادر سبز می‌شود 🟢 و زمان فریز می‌شود
7. سرعت شما نمایش داده می‌شود 🎯
